# Анимация и эффекты Wallpaper-MY

В Kdenlive эффект можно применить к клипу или целой дорожке, сложить несколько эффектов и сохранить их как пресет. Параметры на таймлайне меняются по ключевым кадрам. В Wallpaper-MY дорожка соответствует одному плану обоев, а её рецепт хранится в JSON. [Стек эффектов Kdenlive](https://docs.kdenlive.org/en/effects_and_filters.html) · [Пример анимации цвета](https://docs.kdenlive.org/en/getting_started/quickstart.html)

Плавная интерполяция Kdenlive на сплайне Catmull–Rom иногда выходит за значения соседних кадров. У Wallpaper-MY режим `smooth` плавно стартует и замедляется в конце каждого отрезка, сохраняя значения между заданными точками. Для равномерного изменения есть `linear`, для скачка на следующем кадре — `hold`. Как и в уроках Shotcut по работе с ключами, эффект стоит сначала посмотреть на коротком превью. [Разбор интерполяции Kdenlive](https://docs.kdenlive.org/en/tips_and_tricks/useful_info/smooth_keyframe_interpolation.html) · [Видео Shotcut о фильтрах и ключевых кадрах](https://shotcut.org/tutorials/)

## Пример рецепта

```json
{
  "preset": "tidal-garden",
  "duration": 8,
  "fps": 15,
  "tracks": {
    "atmosphere": {
      "effects": [
        {"type": "caustics", "strength": {"keys": [[0, 0.55], [0.4, 0.95], [1, 0.55]]}},
        {"type": "bloom", "strength": 0.3, "scale": 1.2}
      ]
    },
    "foreground": {
      "base": true,
      "effects": [{"type": "wave", "strength": 0.55}]
    },
    "particles": {
      "effects": [{"type": "particles", "strength": 0.8}]
    }
  }
}
```

- `duration` задаёт длину цикла в секундах, `fps` — частоту до 24 кадров в секунду. Один цикл содержит от 2 до 144 кадров.
- Планы от дальнего к ближнему расположены в порядке `background`, `atmosphere`, `middle`, `surface`, `foreground`, `particles`. До трёх планов поверх `background` можно анимировать одновременно. `base: true` берёт исходное изображение плана из пресета, иначе стек начинается с прозрачного слоя.
- `strength` (0–1) и `scale` (0,3–3) принимают число или массив ключевых кадров внутри `keys`. Каждый ключ имеет вид `[доля цикла, значение, режим до следующей точки]`. Режим по умолчанию — `smooth`. Используйте одинаковые значения в точках `0` и `1` для замыкания цикла. У `hold` переход к следующему значению резкий.
- `cycles` задаёт целое число повторов движения за цикл от −4 до 4. Ноль фиксирует геометрию эффекта, оставляя анимацию его параметров, отрицательное число обращает ход движения. Генерирующие эффекты поддерживают `color` и `secondary` в формате `#RRGGBB`.

## Что меняется в кадре

| Эффект | Действие |
| --- | --- |
| `aurora` | Меняет изгиб, толщину и яркость отдельных лент сияния. |
| `haze` | Формирует меняющиеся по форме и плотности полосы дымки. |
| `caustics` | Создаёт световые лучи и меняющийся узор от пересечения волн. |
| `ripples` | Искажает полосы бликов и распространяет их по поверхности воды. |
| `particles` | Даёт частицам независимые траектории и ритмы свечения. |
| `wave` | Деформирует результат предыдущих эффектов или исходный слой с `base: true`. Нижний край закреплён. |
| `bloom` | Расширяет мягкий ореол вокруг уже нарисованного света, сохраняя резкое ядро. |

Стабильный силуэт помогает заметить изменение света и формы. В Aurora Fjord гора и луна служат неподвижными ориентирами. Сила отражения достигает пика чуть позже сияния, а частицы в Tidal Garden получают разные фазы, чтобы не пульсировать в унисон. Для мягкого ореола поместите `bloom` после эффекта, который рисует свет. [Каналы прозрачности и композиция в Kdenlive](https://docs.kdenlive.org/en/compositing/alpha_channels.html)

`--gif` сохраняет совмещённое превью без i3. Для быстрого просмотра используйте небольшой холст, например 800×300. При `--still --gif preview.gif` в комплект для i3 попадают статичные слои, а GIF по-прежнему показывает весь цикл. Для палитры Material You всегда используется плоский PNG первого кадра.
